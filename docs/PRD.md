# Product Requirements

Bigyard OS coordinates 16 AI workforce departments under one human CEO. It is an internal operating system, not a commercial SaaS platform. AI employees perform work with observable outputs and escalation.

Initial Social Media roles: manager, researcher, writer, graphic producer, video producer, QA, publisher/analyst. Requirements: schedules; sourced research; captions/scripts/CTAs; 1080x1350 graphics; 1080x1920 Remotion/FFmpeg videos; previews; QA that blocks failures; approval state; platform-compliant authorized posting; idempotency; analytics; job records and budget controls.

No new paid API or subscription use without approval. Canva is available for manual template creation and exports but unattended API access is not assumed. The Mac sleeping stops local jobs. External outreach, pricing, money, and deployments require human approval.
